# Route to Rome Attack

Currently, this repository contains the core components of the Route to Rome Attack. The complete pipeline and end-to-end execution scripts will be released as soon as possible.


## Acknowledgments

This project builds upon and draws inspiration from several excellent open-source repositories. We distinguish them between attack algorithms and router datasets/benchmarks:

**Optimization Models / Algorithms**
* [nanoGCG](https://github.com/GraySwanAI/nanoGCG)

**Router Models, Datasets, and Benchmarks**
* [RouteLLM](https://github.com/lm-sys/RouteLLM)
* [RouterDC](https://github.com/shuhao02/RouterDC)
* [RouterEval](https://github.com/MilkThink-Lab/RouterEval)
* [LLMRouterBench](https://github.com/ynulihao/LLMRouterBench)
* [RouterArena](https://github.com/RouteWorks/RouterArena)
